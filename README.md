# Alyn SA-MP Mobile — WebView Implementation

This project is based on the **Alyn SA-MP Mobile v17.x source** (March 2025), with a focus on implementing WebView functionality into the existing SA-MP Mobile client.

## Requirements

* Android Studio
* JDK 17
* Android SDK 35
* Android NDK 25.1.8937393
* CMake

## Setup & Build

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Install the required SDK and NDK versions listed above.
4. Configure your own signing settings for release builds.
5. Sync Gradle and build the project.

The project supports **`armeabi-v7a`** and **`arm64-v8a`**.

**Note:** The client requires GTA: San Andreas Android **version 2.10** and its game data to run.
